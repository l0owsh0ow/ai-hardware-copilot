# 演示与评委脚本（现场 ~5 分钟 + 提交摘要）

> 配合 README 一键启动使用。定位：把「RAG 防幻觉 + 可溯源」讲成核心贡献，而非「UI 好用」。

## A. 现场演示（约 3–5 分钟）

### 开场（约 30 秒）
> 很多同学做课程设计/电赛/毕设，第一步就卡在选型：不会看参数、怕买错，用 ChatGPT 又怕它编型号。我做了一个开源的 AI 硬件选型助手，把这句话变成一份能直接下单、每个器件都可溯源的 BOM。

### 核心演示（2–3 分钟，走一遍全链路）
1. 打开首页，输入一句需求：`做一个低功耗蓝牙温湿度传感器，电池供电，工作半年以上`。
2. 展示**参数确认页**：8 个参数已被自动推断补全，均可编辑。重点讲：「AI 会错，允许用户纠正 = 信任」。
3. 点击推荐：展示 **Top5**，每张卡片含匹配度、推荐理由、价格/库存/Datasheet/采购链接。强调：库外器件会标「立创商城」来源。
4. 打开某个器件详情页，展示 **Datasheet / 商城溯源**链接。
5. 勾选加入 BOM → 一键生成 → 导出 **Excel / CSV**（数量可改，实时算总价。强调：全链路闭环）。
6. （加分项）切到管理后台 `/admin`，展示**埋点漏斗**与**知识库管理 + 重建索引**。

### 一句话收尾（约 30 秒）
> 关键不是「界面好用」，而是**它不会骗你**：AI 只能从真实数据里选，型号回数据库交叉验证，每个推荐都能溯源到官方 Datasheet 或商城详情页。

## B. 现场 QA 预判

| 提问 | 应答要点 |
|------|----------|
| 和通用 ChatGPT 有什么区别？ | 它只在真实数据里选、不编型号，且每个推荐可溯源到 Datasheet/商城 |
| 知识库只有 100 个够吗？ | 库内提质 + 立创**实时检索**（库外在售）双轨；立创不可用自动降级到本地 |
| 数据会不会造假？ | 立创走社区公开接口 jlcsearch；价格/库存为快照，页脚已免责 |
| 本地模型怎么用？ | 接 Ollama GLM-4-9B，零成本/数据不出机，个人主页可一键切换 |
| 有没有真实用户数据？ | 5 位学生深度访谈 + 23 份问卷为**前测**；已内置埋点漏斗与 20 场景评估集（完整验证计划见项目档案） |

## 一、AI 承担的两个任务

1. **需求解析**：自然语言 → 结构化参数（9 字段 JSON）
2. **候选排序 + 推荐理由**：从检索候选中选 Top5 + 写理由 + 评分

## 三、已验证数据

### DeepSeek（云端基线）

- 6/6 场景成功，平均 12.0s，推荐全部合理
- 解析字段完整（含推断字段）

### 本地 GLM-4-9B（零成本）

- 6/6 场景成功，平均约 22s
- 核心解析字段 6/6 正确；推荐 5/6 合理
- 差距：可选字段常缺、推荐数量偶偏少、理由偏模板化

### 结论

- 本地模型达到"主流场景够用"；DeepSeek 用于高质量/演示场景
- 双模式由个人主页一键切换，不重新部署

## 四、架构速览

```
用户需求 → [LLM 解析] → 结构化参数 → 用户确认
    → [向量+关键词双路检索] → [结构化过滤] → [品类均衡压缩]
    → [LLM 排序+理由（禁编型号）] → [SQLite 验证] → Top5
                                      ↑
                              LLM 供应商：DeepSeek / GLM-4-9B / 规则
```

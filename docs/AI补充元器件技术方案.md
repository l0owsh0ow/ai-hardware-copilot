# AI 补充元器件（库外实时检索 + 溯源）技术方案

> 状态：**已实现**。采用「联网检索 / 商城搜索 → LLM 从真实结果选」正解路线，
> 而非让 LLM 凭空生成型号再补来源（那会编造链接）。

## 一、接入方式

- **未用立创官方 API**：需立创企业账号 + 审核申请，个人项目拿不到。
- **实际接入**：免费 `jlcsearch` 社区 API（`https://jlcsearch.tscircuit.com`），
  数据同样来自立创，无需鉴权，返回**在售、库存、人民币价格、参数描述**。
- 溯源链接：立创商品详情页 `https://item.szlcsc.com/<LCSC编号>.html`（含参数/价格/Datasheet）。

## 二、推荐流程（双轨）

| 环节 | 数据来源 | 溯源 |
|---|---|---|
| 本地知识库 RAG | 已收录 100+ 元器件（ChromaDB） | 库内 Datasheet |
| **立创实时检索** | 按需求关键词搜立创在售（jlcsearch） | 立创商品详情页 |

两轨候选合并 → DeepSeek 排序/写理由 → 输出去重、带溯源的推荐。

## 三、关键实现

- `backend/app/services/lcsc_service.py`：搜索 + 规范化 + 品类推断 + 溯源链接生成。
- `recommend()`：按结构化参数生成搜索词（传感器/通信/主控/电源），实时检索立创，
  与本地候选合并后交给 LLM，立创候选完整保留（真实数据，不存在幻觉）。
- 配置开关：`ENABLE_LCSC`（默认 `1`=开启；设 `0` 关闭，回退纯本地库）。
- 标签：库外器件打「立创商城」来源，推荐理由与溯源链接随卡片展示。

## 四、明确不做

- 立创/库外器件**不自动入库**：只做"推荐 + 溯源"，要成为知识库须人工审核。

## 五、风险与边界

- jlcsearch 是社区/非官方接口，**不是立创官方合同 API**；数据源自立创但接口稳定性、
  字段可能变动，需容错（失败自动回退本地库，不影响主流程）。
- 依赖网络：本地/后端需能访问外网才能实时检索；离线时自动退化为纯本地库推荐。
- 价格/库存为抓取快照，非绝对实时，页面已注明"价格仅供参考，以实际采购为准"。

## 六、产品意义

- 回答"100 个元器件不够"：**知识库扩充（提质） + 立创实时检索（扩覆盖）** 双轨。
- 把"可信"从"我们保证真实"升级为"**告诉你依据，你可以自己核实**"（溯源到商品页/Datasheet）。

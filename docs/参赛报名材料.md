## 1. 一句话定位（报名用）

> 面向电子专业学生与硬件爱好者的开源 AI 硬件选型助手——输入一句自然语言需求，即可获得「防幻觉、可溯源、能下单」的元器件推荐与 BOM，覆盖 100+ 精选知识库与立创实时在售，全流程开箱即用。

**更口语的一句**：用一句大白话，让 AI 帮你把硬件选型做完——从需求到一份可核实的、能直接下单的物料清单，不编型号、不买错。

## 2. 要解决的问题

1. **选型工具门槛高**：立创/DigiKey 的参数筛选器对新手不友好，参数看不懂、翻译成中文更难。
2. **通用大模型不可信**：ChatGPT 等会凭空编型号、编造不存在的链接，硬件选型是「信任成本极高」的决策。
3. **选完还要手工整理**：选好元器件后，还要手动去做物料清单（BOM），效率低、易漏项。

## 3. 核心亮点（评委视角）

1. **防幻觉三层的核心贡献**：`候选约束（LLM 只能从检索结果里选）→ SQLite 交叉验证（型号必须真实存在）→ Datasheet / 商城溯源（每个推荐可核实）`。把「可信」做成工程承诺，而不是提示词技巧。
2. **双轨覆盖**：100+ 精选元器件知识库（库内）+ 立创实时在售检索（库外，走社区公开接口 jlcsearch），既不缺料又不编型号。
3. **参数自动推断补全**：用户描述信息不足时，AI 依据应用场景主动推断供电 / 通信 / 接口 / 电压等，显著降低输入门槛。
4. **全链路闭环**：一句话 → 参数解析 → 防幻觉推荐 → BOM → Excel / CSV 导出。
5. **双模型 + 降级兜底**：DeepSeek 云端（高质量）+ 本地 GLM-4-9B（Ollama，零成本 / 数据不出机）；LLM 调用失败自动降级规则模式，**任何输入都有结果**。
6. **开箱即用**：Clone 后一条命令跑通，无需 API Key、无需 Ollama。
7. **商业级完整度**：P0 安全（Token 鉴权 / 限流 / Key 不入库 / 降级链）+ P1 运营（埋点漏斗、知识库管理后台、数据看板、反馈入口）。

## 4. 技术实现要点

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | Next.js 14 + React + TypeScript + TailwindCSS | 组件化、类型安全、移动适配 |
| 后端 | Python + FastAPI + Pydantic | AI 生态、自动文档、数据校验 |
| AI | DeepSeek（云端）/ GLM-4-9B（本地 Ollama） | 双模式可切换：云端质量与本地零成本/隐私 |
| 检索 | ChromaDB + sentence-transformers（384 维中文向量）+ 关键词双路 + 结构化过滤 | 语义检索 + 召回兜底 |
| 库外覆盖 | jlcsearch（立创社区公开接口）实时检索在售 + 商城溯源 | 扩覆盖且不编型号；官方 API 需企业资质 |
| 抗幻觉 | RAG 三层：候选约束 / SQLite 交叉验证 / Datasheet 溯源 | 只推真实、可核实型号 |
| 数据 | SQLite（事实源）+ JSON（源数据）+ 向量库 | 双库分工：向量管找、关系库管真 |
| 可靠性 | LLM 失败→规则模式、全程超时兜底、degraded 标识 | 保证任何输入都有结果，绝不 500 |

## 5. 开源完整性 / 文档

- **一键启动**：`start.bat`（Windows）/ `start.sh`（macOS·Linux），零 Key、零 Ollama 可跑通全链路。
